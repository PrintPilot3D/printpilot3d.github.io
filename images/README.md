# Photos

Put a product photo in this folder, then turn on its `image` line in `script.js`.

Example: save a picture as `images/headphone-stand.jpg`. In the Headphone Stand product, change

```
// image: "images/headphone-stand.jpg",
```

to

```
image: "images/headphone-stand.jpg",
```

The drawing stays until that line is turned on. Use a photo you took. Do not use brand logos.
